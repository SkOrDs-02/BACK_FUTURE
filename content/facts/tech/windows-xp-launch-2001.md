У 90-х у Microsoft було дві окремі лінійки систем. Домашні Windows 95, 98 і Me спирались на стару основу DOS, а професійні Windows NT і Windows 2000 мали нове ядро NT, але орієнтувались на офіси й сервери.

**25 жовтня 2001 року** Microsoft [оголосила про світовий продаж Windows XP](https://news.microsoft.com/source/2001/10/25/windows-xp-is-here/) на презентації в Нью-Йорку, яку вів Білл Гейтс. XP об'єднала обидві гілки: домашня версія отримала те саме **ядро NT**, що й корпоративна. Як [писав eWeek](https://www.eweek.com/news/at-xp-launch-gates-bids-adieu-to-dos/), на запуску Гейтс фактично попрощався з DOS.

Для домашнього користувача це означало перехід на ту саму основу, яку раніше мали лише офісні машини, і нове оформлення зі знаменитими шпалерами із зеленим пагорбом. Запуск відбувся через шість тижнів після терактів 11 вересня, тож очікування щодо продажів були скромнішими, ніж планувала компанія.

Windows XP стала однією з найдовговічніших систем Microsoft. Основна підтримка завершилась **14 квітня 2009 року**, а розширена **8 квітня 2014 року**: після цього, як [попереджала компанія](https://www.microsoft.com/en-us/security/blog/2013/08/15/the-risk-of-running-windows-xp-after-support-ends-april-2014/), XP перестала отримувати оновлення безпеки.
