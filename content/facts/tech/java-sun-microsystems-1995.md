На початку 1990-х програму, написану мовою C чи C++, треба було окремо компілювати для кожної комбінації операційної системи й процесора: Windows, різних версій Unix, Mac. Веб, що тільки з'являвся, показував статичні сторінки з текстом і картинками, а будь-яку взаємодію обробляв сервер.

**23 травня 1995 року** на конференції SunWorld компанія Sun Microsystems оголосила мову програмування **Java** і написаний нею браузер **HotJava**. У [пресрелізі Sun](https://tech-insider.org/java/research/1995/0523.html) HotJava описували як інструмент, що завантажує в браузер невеликі програми, аплети, і виконує їх на комп'ютері користувача. Альфа-версії для SunOS, Solaris і Windows NT можна було безкоштовно завантажити для некомерційного використання. На тій самій сцені Марк Андріссен з Netscape повідомив, що Netscape ліцензує Java для свого браузера.

Головна ідея Java полягала у **віртуальній машині**. Компілятор перетворює програму не на машинний код конкретного процесора, а на проміжний байт-код, який виконує віртуальна машина Java на будь-якій платформі. Звідси гасло **«напиши один раз, запускай будь-де»**. Мова також мала автоматичне керування пам'яттю, що позбавляло програмістів значної частини помилок, типових для C++.

Аплети в браузері згодом поступилися JavaScript, яку Netscape випустила того ж 1995 року і назвала на хвилі популярності Java, хоча це інша мова. Натомість сама Java прижилася на серверах, у банківських і корпоративних системах, у навчанні програмуванню, а з 2008 року стала основною мовою розробки застосунків для Android.
